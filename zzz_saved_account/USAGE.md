# 已保存账号免密切换 · 使用说明

> **注意：这是一个会改一条龙登录流程的补丁。** 插件一被加载就生效——不点本应用、只是开着
> 一条龙，它也会接管「进入游戏 / 切换账号」流程：需要登录时先让游戏登出当前账号（退出并
> 保留登录记录），再点选你配置的那个已保存账号进游戏。不想让它管，就把目标账号留空或不装。

一条龙原生的多账号切换是「退出当前账号 → 输入下一个账号的密码」。本插件改成直接点选
绝区零 miHoYo 登录页里已经保存的登录记录，不用再输密码。

## 使用步骤

1. **安装**：把 `zzz_saved_account/` 整个目录放进一条龙的 `plugins/` 下（或从插件商店订阅），
   然后**完全退出并重启一条龙**。日志出现 `已保存账号补丁已生效` 才算加载成功。
2. **查掩码**：打开游戏到标题界面 → 点右下角的圆形箭头 → 选「退出并保留登录记录」→
   点「确定」→ 登录页上显示的那行号码（形如 `138******00`）就是要填的掩码。
3. **填账号**：「应用运行」页找到 **已保存账号免密切换** 卡片，点右侧齿轮，按实例各填一行掩码，
   失焦自动保存。留空表示该实例不启用插件。掩码保存在插件自己的数据目录
   `plugin_data/zzz_saved_account/targets.json`，不会写进一条龙的账号配置。
4. **自动切号（可选）**：想把两个账号轮流跑，就在「一条龙运行」页把 **运行实例** 改成 **全部实例**。
5. **日常使用**：直接跑一条龙；或只换号时跑「应用运行」里的 **已保存账号免密切换**
   （游戏没开就先拉起游戏，在大世界就先登出，最后都会选号并进入游戏）。

## 怎么确认它在工作

| 日志关键字 | 含义 |
| --- | --- |
| `已保存账号补丁已生效` | 插件加载成功 |
| `标题界面点击「切换账号」图标 ...` | 在标题界面找到并点击了切换图标（模板匹配） |
| `退出确认框点选「退出并保留登录记录」 ...` | 在退出确认框里选中了保留记录 |
| `登录页点击账号下拉箭头 ...` | 点开了账号下拉列表 |
| `检测到已保存账号弹窗，点选目标账号 ...` | 命中了目标账号并点击 |
| `已选好账号，点击「进入游戏」 ...` | 选完账号后点了进入游戏 |
| `未找到目标账号（画面中识别到 N 条登录记录）` | 没匹配到，会重试 3 次后报错 |

> 日志里不会出现账号数字，只写识别到几条记录。

## 常见问题

- **跑了没反应**：在齿轮弹窗里确认该实例填了掩码，改完重启一条龙。
- **提示「未找到目标账号」**：掩码写错，或这个账号当初没勾「保留登录记录」；按游戏登录页显示的掩码改。
- **提示「补丁未生效」**：插件没加载，确认目录在 `plugins/` 下或在商店里已订阅；一条龙大版本升级后可能
  需要等插件适配。
- **一直停在同一个账号**：「运行实例」还是「仅运行当前」，改成「全部实例」才会执行切号。
- **怎么清数据**：删插件目录后再删 `plugin_data/zzz_saved_account/`。

## 说明

- 只处理国服客户端的 miHoYo 账号弹窗；B 服、国际服走原生流程。
- 账号掩码只写在本机 `plugin_data/zzz_saved_account/targets.json`，插件不联网、不上传任何账号信息。
- 插件会读写 `plugin_data/zzz_saved_account/`（`filesystem`），不碰其它文件。
- 插件用 monkey-patch 给一条龙的进入游戏流程打补丁，一条龙升级后可能需要适配。

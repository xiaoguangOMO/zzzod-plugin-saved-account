# 已保存账号免密切换

一条龙原生的多账号切换流程是：退出当前账号 → 在登录界面输入下一个账号的账号密码。
但绝区零会把登录过的账号保存在 miHoYo 账号选择弹窗里，点一下对应记录就能直接登录，
完全不需要密码。本插件给一条龙的进入游戏流程打补丁，在需要登录时自动点选当前实例
配置的目标账号。

适用场景：一台电脑上有多个绝区零账号、且都勾选过「保留登录记录」，跑一条龙时
希望它自己在账号之间来回切。

## 使用说明

不确定从哪下手？在一条龙的「插件管理」里点开「已保存账号免密切换」，详情弹窗里显示的
这段说明就是本文件的精简版：本地插件没有商店条目，插件会自己把 README 渲染进来。

### 第 1 步：安装

插件商店里订阅安装；或把 `zzz_saved_account/` 整个目录放进一条龙的 `plugins/` 下。
装完**完全退出并重启一条龙**（不是最小化），日志出现 `已保存账号补丁已生效` 才算加载成功。

### 第 2 步：查到自己账号的掩码

打开游戏到标题界面 → 点右下角的圆形箭头图标 → 选「退出并保留登录记录」→ 点「确定」→
登录页上显示的那行号码（形如 `138******00`）就是掩码。

> 这一步只是为了让插件知道「这台电脑上哪个账号是你的目标账号」。插件靠掩码数字
> 在账号列表里认人；同一台电脑上有多个账号时，靠它区分。

### 第 3 步：给每个实例填上目标账号

**方式一：界面里改（推荐）**

「应用运行」页面找到 **已保存账号免密切换** 这张卡片，点右侧齿轮按钮，弹窗里会按实例
（实例 01、实例 02……）各列一行输入框，把掩码填进去即可，**失焦自动保存**，不用改文件，
当前实例立即生效。

**方式二：手改配置文件**

编辑 `config/<实例号>/game_account.yml`，加一行：

```yaml
game_path: E:\miHoYo Launcher\games\ZenlessZoneZero Game\ZenlessZoneZero.exe
saved_account: '138******00'
```

- 把 `138******00` 换成第 2 步看到的掩码。
- **必须加引号**：值里有 `*`，不加引号 YAML 会把它当成别名并报错。
- 实例 01、02 各写各的；留空或删掉这一行 = 该实例不启用插件，行为与原生完全一致。
- 改完必须重启一条龙，运行中的进程不会重新读这个文件。

### 第 4 步：让一条龙自动切号（可选）

如果想让一条龙在多个账号之间自动来回切，在「一条龙运行」页面把 **运行实例**
改成 **全部实例**。只运行当前实例时，一条龙不会执行切号流程。

### 第 5 步：日常使用

- **跑一条龙**：到了登录阶段会自动切到当前实例的目标账号；
- **只想换号**：「应用运行」里跑 **已保存账号免密切换**，它会真的操作游戏：
  - 游戏没开：先拉起游戏，再到标题界面选号进游戏；
  - 游戏停在标题界面或任何账号相关弹窗：直接选号进游戏；
  - 游戏已经在大世界：从菜单登出（保留登录记录），回到账号列表后选号进游戏。

## 怎么确认它在工作

| 日志关键字 | 含义 |
| --- | --- |
| `已保存账号补丁已生效` | 插件加载成功 |
| `标题界面点击「切换账号」图标 ...` | 在标题界面找到了图标并点击（模板匹配，不依赖固定坐标） |
| `退出确认框点选「退出并保留登录记录」 ...` | 在退出确认框里选中了保留记录 |
| `退出确认框点击「确定」 ...` | 点了确定 |
| `登录页点击账号下拉箭头 ...` | 在登录页点开了账号下拉 |
| `检测到已保存账号弹窗，点选 xxx (位置 ...)` | 在列表里命中并点击了目标账号 |
| `已选好账号 xxx，点击「进入游戏」 ...` | 选完账号后点了进入游戏 |
| `未找到已保存账号 xxx，当前识别到: ...` | 没匹配到，会重试 3 次后报错并列出实际识别到的账号 |

## 覆盖的画面

| 画面 | 处理 |
| --- | --- |
| 标题界面 | 模板匹配右下角的「切换账号」圆形图标（图标随镜头漂移，不用固定坐标） |
| 「退出登录」确认框 | 按 OCR 识别「退出并保留登录记录」与「确定」，点它们的实际位置 |
| miHoYo 登录页（只显示一行账号） | 点这一行右侧的 ▼ 下拉箭头，展开全部已保存记录 |
| 展开后的账号列表 | 按掩码手机号点选目标账号 |
| 选完账号的登录页 | 点「进入游戏」开始加载 |
| 输入手机号/密码页 | 点左上角返回，回到账号列表（兜底分支） |
| 原生「更多登出确认」节点 | 同样按上面的确认框处理，不再卡死在只认一个「确认」按钮 |

## 判断逻辑

- 只在 `saved_account` 非空时介入；其余画面完全交回原生逻辑。
- 完整流程：标题界面点「切换账号」→ 确认框选「保留记录」+「确定」→ 登录页默认只显示
  当前账号那一行（右侧 ▼）→ 点 ▼ 展开全部记录 → 点目标账号 → 点「进入游戏」。
- 展开后的列表最上面一行是「当前账号」摘要，会和下面真正的登录记录显示同一个号码，
  所以同一个号码出现两次时点击更靠下的那一行。
- OCR 可能把 `138******00` 拆成 `138` 和 `*00` 两个框，插件按行拼接后再比较数字，
  并纠正 `O→0`、`I→1`、`S→5` 等常见形近字。
- 点完账号会等 8 秒再允许重复点击；连续 3 次都点不到/点不动目标时，一条龙会报错并
  给出实际识别到的账号列表，避免静默失败。
- 配了 `saved_account` 时 `has_login_info` 视为已配置，所以「全部实例」模式下第一个
  实例也会先切号，不会直接用游戏当前登着的账号。

## 常见问题

**Q：跑了应用，游戏没任何反应？**
先在齿轮设置弹窗里确认该实例填了掩码（或检查 `config/<实例号>/game_account.yml` 里的 `saved_account` 是否为空、有没有加引号），改完要重启一条龙。

**Q：提示「未找到已保存账号 xxx」？**
掩码写错了，或者这个账号当初登录时没勾「保留登录记录」。报错信息里会列出它实际
识别到的账号，照着改成那个值即可。

**Q：提示「补丁未生效」？**
一条龙没有加载到插件。确认插件目录在 `plugins/` 下、或在插件商店里已订阅并重启、日志里有 `已保存账号补丁已生效`；
一条龙升级后如果 `EnterGame` / `SwitchAccount` 的方法被改名，也会出现这个提示，
需要等插件更新。

**Q：两个账号来回切，结果一直停在同一个账号？**
「运行实例」还是「仅运行当前」。要跑完整的一轮切号，必须改成「全部实例」。

## 注意

- 如果游戏窗口不是 16:9、或游戏内 UI 缩放到与 1920x1080 差异很大，识别区域可能需要
  微调：`saved_account_patch.py` 顶部的 `DIALOG_RECT`、`LOGOUT_DIALOG_RECT`、
  `SWITCH_ICON_CROP`、`ACCOUNT_DROPDOWN_CROP`、`ENTER_GAME_RECT`。
- 插件通过 monkey-patch `EnterGame` / `SwitchAccount` 生效，属于对一条龙内部流程的补丁；
  一条龙升级后需要按新版本代码适配。
- 只处理国服客户端（`cn`）的 miHoYo 账号弹窗；B 服、国际服走原生流程。
- 账号掩码只写在本机 `config/<实例>/game_account.yml` 里，插件不联网、不上传任何账号信息。

## 风险声明

插件会模拟点击游戏界面（`automation`）并做本地 OCR（`ocr`），属于自动化操作，
请自行评估账号风险；建议只在个人电脑上使用。
